CHICAGO BARBER — IMPLEMENTAÇÃO DA AGENDA ADMINISTRATIVA

O QUE ESTE PACOTE ADICIONA
- /admin/agenda: visualização semanal e programação diária.
- Consulta dos agendamentos existentes, incluindo e-mail do cliente e serviços.
- Remarcação com validação de horário de funcionamento e conflito.
- Cancelamento de agendamentos.
- Link "Gerenciar agenda" no menu de perfil do administrador (desktop e celular).
- Funções SQL protegidas por public.is_admin().

COMO APLICAR NA RAIZ DO PROJETO
1. Copie a pasta app/admin/agenda para a pasta app/admin/ do seu projeto.
2. Copie a pasta app/api/admin/appointments para app/api/admin/ do seu projeto.
3. Substitua components/navbar.tsx pelo arquivo deste pacote.
4. Copie o arquivo supabase/migrations/20261103000000_admin_appointments.sql para a pasta de migrations do projeto.
5. No Supabase, abra SQL Editor, crie uma consulta, cole o conteúdo desse arquivo SQL e execute.
6. Rode npm run build para conferir a compilação e depois npm run dev para testar localmente.

REQUISITOS
- O projeto já deve ter a configuração @/lib/supabase.
- A migração 20261014000000_admin_roles.sql já deve ter sido executada e public.is_admin() deve existir.
- A estrutura esperada é a usada pela API de agendamentos existente: appointments, appointment_services e services, com os campos referenciados no código atual.
- O status de cancelamento utilizado é "cancelled"; agendamentos ativos são os demais status.

OBSERVAÇÕES
- A tela só é liberada para usuários cujo perfil tenha role = 'admin'.
- O acesso aos dados e as alterações também são verificados no banco, não apenas escondidos no menu.
- O nome do cliente usa full_name/name dos metadados da conta; se não existir, mostra o e-mail cadastrado.
- Não inclui chat, WhatsApp ou Instagram nesta etapa.
